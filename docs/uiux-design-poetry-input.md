# 诗歌录入 UI/UX 设计规范

> **版本**：v1.0 · **日期**：2026-09-06
> **适用页面**：诗歌录入（create.vue）、诗歌编辑（edit.vue）

---

## 1. 现状问题分析

### 1.1 交互问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 标签输入 | 纯文本逗号分隔 | 无法复用已有标签，易拼写不一致 |
| 分类选择 | 数字 ID 输入 | 用户不知道 ID 是什么，容易填错 |
| 内容区域 | 仅 4 行 textarea | 长诗编辑体验差 |
| 封面图 | 仅 URL 文本输入 | 无法预览，容易填错 |
| 表单布局 | 单列超长滚动 | 字段多，填写疲劳 |

### 1.2 一致性问题

| 问题 | 录入页 | 编辑页 |
|------|--------|--------|
| 标签字段 | ❌ 无 | ✅ 有 |
| 元信息卡片 | ❌ 无 | ✅ 有 |
| 删除按钮 | ❌ 无 | ✅ 有 |

## 4. 组件设计

### 4.1 标签输入组件（TagInput）

```
┌─────────────────────────────────────────────────────────────────────┐
│  [唐诗 ✕] [山水 ✕] [抒情 ✕] [输入新标签或搜索...              ]  │
└─────────────────────────────────────────────────────────────────────┘
```

**交互**：
- 输入文字后按回车或逗号添加
- 输入时显示已有标签自动完成下拉
- 点击 ✕ 删除标签
- 最多 10 个标签

**规格**：
| 属性 | 值 |
|------|-----|
| 标签样式 | `Badge variant="secondary"` + 删除按钮 |
| 自动完成 | Popover 下拉，显示标签名 + 引用数 |
| 最大标签数 | 10 |

### 4.2 分类选择组件（CategorySelect）

```
┌──────────────────────┐
│ 唐诗三百首         ▼ │
└──────────────────────┘
        ↓ 展开
┌──────────────────────┐
│ ● 全唐诗             │
│ ○ 唐诗三百首         │
│ ○ 宋词三百首         │
│ ○ 诗经               │
└──────────────────────┘
```

**交互**：
- 下拉显示分类树
- 支持搜索过滤
- 选择后显示分类路径

### 4.3 折叠区域（Collapsible）

```
┌─────────────────────────────────────────────────────────────────────┐
│  ▶ 翻译 / 赏析                                    2 项可选内容     │
└─────────────────────────────────────────────────────────────────────┘
                        ↓ 点击展开
┌─────────────────────────────────────────────────────────────────────┐
│  ▼ 翻译 / 赏析                                                     │
│  ─────────────────────────────────────────────────────────────────  │
│  翻译  [Textarea]                                                   │
│  赏析  [Textarea]                                                   │
└─────────────────────────────────────────────────────────────────────┘
```

## 5. 交互细节

### 5.1 内容编辑器

| 功能 | 说明 |
|------|------|
| 自动扩展 | 输入时 textarea 自动增高（min 6 行，max 20 行） |
| 格式保留 | 保留换行和空格 |
| 字数统计 | 右下角显示当前字数 |

### 5.2 保存策略

| 操作 | 行为 |
|------|------|
| 保存草稿 | 状态设为 draft，保存后留在页面（编辑页）或跳转（录入页） |
| 发布 | 状态设为 published，保存后跳转列表 |
| 离开提示 | 有未保存内容时，离开前 confirm 提示 |

### 5.3 验证规则

| 字段 | 验证 | 错误提示 |
|------|------|----------|
| 标题 | 非空，≤50 字 | "请输入标题" |
| 作者 | 非空 | "请输入或选择作者" |
| 内容 | 非空，≤2000 字 | "请输入内容" |
| 标签 | 每个 ≤10 字，总数 ≤10 | "标签过长" / "最多 10 个标签" |

## 7. 响应式

### 7.1 桌面（≥ 1024px）
- 双列布局
- 作者信息与分类标签并排

### 7.2 平板（768-1023px）
- 单列布局
- 保留分组卡片

### 7.3 手机（< 768px）
- 单列紧凑布局
- 辅助内容默认折叠

| 标签删除 | Scale out + fade | 150ms |

## 9. 验收标准

| 测试项 | 标准 |
|--------|------|
| 标签输入 | 支持回车添加、自动完成、删除 |
| 分类选择 | 树形展示，可选择任意层级 |
| 内容编辑 | 自动扩展，保留格式 |
| 表单验证 | 必填项为空时阻止提交并提示 |
| 保存草稿 | 状态为 draft，不跳转 |
| 发布 | 状态为 published，跳转列表 |
| 编辑回显 | 所有字段正确回显，包括标签 |
| 离开提示 | 有修改时离开确认 |

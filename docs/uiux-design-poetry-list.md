# 诗歌列表页 — UI/UX 设计文档

> **版本**：v1.0 · **日期**：2026-09-06
> **设计系统**：水墨诗意 · 东方雅韵
> **组件库**：shadcn-vue + Tailwind CSS 4

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| **信息层次清晰** | 标题、作者、分类、标签、状态一目了然 |
| **标签可视化** | 直观展示诗文是否带有标签，标签内容可预览 |
| **操作高效** | 常用操作（查看、编辑、发布/归档）一键可达 |
| **批量友好** | 批量操作栏流畅展开，批量标签操作集成 |
| **诗意美学** | 内容预览使用衬线体，体现文化感 |

## 3. 标签列设计

### 3.1 标签展示规则

| 标签数量 | 展示方式 | 示例 |
|----------|----------|------|
| 0 个 | 显示「─」灰色占位 | `─` |
| 1-2 个 | 全部显示 | `🏷思乡` `🏷月亮` |
| 3 个 | 全部显示 | `🏷思乡 🏷月亮 🏷孤独` |
| 4+ 个 | 显示前 3 个 + 数量 | `🏷思乡 🏷月亮 🏷孤独 +2` |

### 3.2 标签 Chip 样式

```vue
<!-- 标签 Chip -->
<span class="tag-chip">
  <Tag class="h-3 w-3" />
  思乡
</span>

<!-- 溢出指示 -->
<span class="tag-overflow">+2</span>

<!-- 无标签 -->
<span class="tag-empty">─</span>
```

#### 颜色方案

| 元素 | 亮色模式 | 暗色模式 |
|------|----------|----------|
| 标签 Chip 背景 | `bg-primary/8` | `bg-primary/15` |
| 标签 Chip 文字 | `text-primary` | `text-primary` |
| 标签图标 | `text-primary/60` | `text-primary/80` |
| 溢出数字 | `bg-muted text-muted-foreground` | `bg-muted text-muted-foreground` |
| 无标签占位 | `text-muted-foreground/40` | `text-muted-foreground/40` |

### 3.3 标签悬停交互

```
悬停标签 Chip 时：
┌─────────────────────────────────────────┐
│  思乡                    关联 180 首诗歌 │
│  ─────────────────────────────────────  │
│  最近使用：2026-09-01                   │
│  [查看标签]  [编辑标签]                 │
└─────────────────────────────────────────┘

点击标签 Chip → 弹出该标签下的诗歌列表（或跳转标签页）
点击溢出数字 → 展开完整标签列表 Popover
```

## 8. 响应式设计

### 8.1 桌面端（≥ 1280px）

完整表格，所有列可见，标签 Chip 最多显示 3 个。

### 8.2 平板端（768px - 1279px）

- 隐藏「翻译/赏析」列
- 标签 Chip 最多显示 2 个
- 操作列折叠为 dropdown

### 8.3 移动端（< 768px）

- 表格改为卡片列表
- 每张卡片展示一首诗的完整信息
- 标签 Chip 完整展示

## 9. 动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 行悬停 | `bg-muted/50` 渐入 | 150ms |
| 标签 Chip 悬停 | 背景加深 | 100ms |
| 批量操作栏展开 | Grid rows 0fr → 1fr | 200ms |
| 标签筛选下拉 | Fade in + slide down | 150ms |
| 标签 Popover | Fade in | 150ms |

## 10. 无障碍设计

| 要求 | 实现 |
|------|------|
| 标签 Chip 有 aria-label | `aria-label="标签：思乡"` |
| 溢出数字可点击 | `role="button"` + 键盘可达 |
| 状态标签有文字说明 | 不仅靠颜色区分 |
| 筛选器有标签关联 | `aria-labelledby` |

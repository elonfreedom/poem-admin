# 顶栏功能评审 & UIUX 优化方案

> **日期**：2026-08-31 · **评审范围**：HeaderBar、Sidebar、Layout、Dashboard

---

## 1. 功能评审 — 发现的问题

### 1.1 HeaderBar 功能问题

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **搜索框纯装饰** | 🔴 高 | 输入框无实际功能，输入后无反应，无搜索结果 |
| 2 | **通知按钮纯装饰** | 🔴 高 | 红点永远显示，点击无效果，无通知中心 |
| 3 | **「个人中心」路由不存在** | 🔴 高 | `/profile` 已被移除，点击会跳转 404 |
| 4 | **「系统设置」路由不完整** | 🟡 中 | `/system/config` 路由不存在（仅有 banner、announcement） |
| 5 | **无移动端适配** | 🟡 中 | 小屏幕下顶栏无响应式处理 |

### 1.2 Sidebar 功能问题

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **菜单无图标** | 🔴 高 | 菜单项只有文字，无图标标识，可识别性差 |
| 2 | **折叠后无意义** | 🔴 高 | 折叠后只显示文字（被截断），无图标无法导航 |
| 3 | **硬编码深色背景** | 🟡 中 | `bg-[#001529]` 与设计系统令牌不统一 |
| 4 | **无暗色模式适配** | 🟡 中 | 侧边栏颜色不随主题切换 |

### 1.3 Dashboard 页面问题

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **仍使用 antd 组件** | 🔴 高 | `a-spin`、`a-row`、`a-col`、`a-card` 未迁移 |
| 2 | **布局不合理** | 🟡 中 | 5 个统计卡片 `span=4` 在小屏拥挤 |

## 2. UIUX 评审 — 发现的问题

### 2.1 顶栏 UIUX

| # | 问题 | 说明 |
|---|------|------|
| 1 | **无背景模糊** | 滚动时顶栏与内容混在一起，缺乏层次感 |
| 2 | **高度偏低** | `h-16` (64px) 偏矮，建议 56-64px 保持精致 |
| 3 | **按钮间距紧凑** | `gap-1` 按钮过于密集，建议 `gap-2` 或更大 |
| 4 | **搜索框占空间但无用** | 占据顶栏主要空间却无功能 |

### 2.2 侧边栏 UIUX

| # | 问题 | 说明 |
|---|------|------|
| 1 | **深色背景突兀** | `#001529` 与浅色内容区对比过强 |
| 2 | **Logo 区域简陋** | 只有文字，缺少品牌图标/印章 |
| 3 | **子菜单缩进不足** | `ml-4` 缩进太小，层级不明显 |
| 4 | **激活态不够突出** | `bg-white/15` 太弱，建议加左侧指示条 |

### 2.3 内容区 UIUX

| # | 问题 | 说明 |
|---|------|------|
| 1 | **内容区边距不一致** | `p-4` 与 `p-5` 混用 |
| 2 | **卡片样式不统一** | 外层 `rounded-lg` 与内层卡片混用 |
| 3 | **面包屑位置** | 面包屑在内容卡片外部，视觉割裂 |

## 3. 优化方案

### 3.1 P0 — 功能修复（必须）

#### 3.1.1 搜索框 → 移除或实现真实搜索

**方案**：实现菜单搜索功能
- 输入时过滤侧边栏菜单项
- 点击搜索结果直接跳转
- 快捷键 `Cmd/Ctrl+K` 聚焦搜索框

#### 3.1.2 通知按钮 → 实现通知中心

**方案**：实现简易通知中心
- 点击展开通知列表（DropdownMenu）
- 显示系统公告/待办事项
- 红点根据实际未读数显示

#### 3.1.3 用户菜单修复

**方案**：
- 移除「个人中心」（路由不存在）
- 保留「系统设置」→ 跳转到 `/system/banner`
- 增加「退出登录」

#### 3.1.4 Dashboard 页面迁移

**方案**：移除 antd 组件，改用 shadcn-vue + Tailwind

### 3.2 P1 — UIUX 优化（短期）

#### 3.2.1 顶栏优化

- 添加 `backdrop-blur` 毛玻璃效果
- 搜索框实现真实功能
- 按钮间距调整为 `gap-2`

#### 3.2.2 侧边栏优化

- 使用设计系统令牌颜色
- 添加菜单图标
- 折叠后显示图标
- 激活态加左侧指示条

#### 3.2.3 内容区优化

- 统一边距为 `p-6`
- 面包屑放入内容卡片头部

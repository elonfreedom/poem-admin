# 侧边栏 & 顶栏 UIUX 深度评审

> **日期**：2026-08-31 · **评审范围**：Sidebar、HeaderBar、Layout
> **参照**：登录页设计语言（水墨诗意 · 东方雅韵）

---

## 1. 整体印象

| 维度 | 评分 | 说明 |
|------|------|------|
| 功能性 | ⭐⭐⭐⭐ | 基本功能完整，搜索框待实现 |
| 视觉一致性 | ⭐⭐⭐ | 侧边栏/顶栏与登录页设计语言脱节 |
| 品牌表达 | ⭐⭐ | 缺少「水墨诗意」品牌元素 |
| 交互反馈 | ⭐⭐⭐ | 基础反馈有，但缺少细节打磨 |
| 信息层级 | ⭐⭐⭐ | 菜单层级可进一步优化 |
| 暗色适配 | ⭐⭐⭐⭐ | CSS 变量覆盖完整 |

### 核心问题

**侧边栏和顶栏与登录页的设计语言不统一。** 登录页有印章、竖排诗句、毛玻璃、暖白/墨黑配色；而主界面侧边栏是标准 shadcn 风格，没有品牌特色。

## 4. 优化方案

### 4.1 P0 — 品牌统一（必须）

#### 4.1.1 侧边栏品牌化

- Logo 区域使用登录页同款印章设计
- 侧边栏背景使用暖色调（亮色）/ 墨色调（暗色）
- 激活态增加左侧 3px 强调条（赭石色/金色）

#### 4.1.2 搜索框功能化

- 实现 ⌘K 快捷键聚焦
- 搜索框聚焦时展开下拉菜单
- 输入时过滤菜单项并显示结果

### 4.2 P1 — 体验优化（短期）

#### 4.2.1 菜单分组

- 添加分组标题：「内容管理」「用户管理」「系统工具」
- 分组标题使用 `text-xs uppercase tracking-wider text-muted-foreground`

#### 4.2.2 子菜单展开动画

- 使用 `<Transition>` 组件包裹子菜单
- 高度过渡：`max-height: 0 → auto`，duration: 200ms

#### 4.2.3 顶栏增强

- 面包屑中增加当前页面标题高亮
- 用户菜单增加角色显示

### 4.3 P2 — 细节打磨（中期）

- 侧边栏滚动时顶部/底部阴影
- 折叠后使用 Tooltip 组件
- 菜单项点击 ripple 效果

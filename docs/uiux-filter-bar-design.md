# 筛选栏 UI/UX 设计规范

> **版本**：v1.0 · **日期**：2026-09-06
> **适用页面**：诗歌列表、作者列表、用户列表等

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **层次分明** | 核心操作（搜索）突出，辅助筛选弱化 |
| **分组清晰** | 相关筛选器就近分组，减少视觉跳跃 |
| **渐进展开** | 常用筛选直接展示，高级筛选折叠 |
| **即时反馈** | 筛选条件变化立即生效，无需点击「确定」 |

---

## 2. 布局方案

### 2.1 推荐方案：搜索 + 行内筛选

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                                                                                │
│  🔍 搜索标题、作者或内容...                    [朝代▼] [状态▼] [标签▼] [更多]  │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

**特点**：
- 搜索框独占一行，视觉焦点集中
- 筛选器在第二行（或同行右侧），紧凑排列
- 「更多」折叠高级筛选（翻译、赏析等低频筛选项）

### 2.2 备选方案：单行紧凑

```
┌────────────────────────────────────────────────────────────────────────────────┐
│  🔍 搜索...  [标题|作者|全部]  [朝代▼] [状态▼] [标签▼] [翻译▼] [赏析▼]      │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 搜索框设计

### 3.1 标准搜索框

```
┌─────────────────────────────────────────────────┐
│  🔍  搜索标题、作者或内容...              ✕      │
└─────────────────────────────────────────────────┘
  ↑                    ↑                      ↑
  └─ 前置图标          └─ placeholder          └─ 清除按钮（有内容时显示）
```

**规格**：
| 属性 | 值 |
|------|-----|
| 高度 | 36px（h-9） |
| 圆角 | 8px（rounded-lg） |
| 前置图标 | Search，16px，左 12px |
| 清除按钮 | X，20px 圆形，右 8px，hover 显示背景 |
| placeholder 色 | `text-muted-foreground` |

### 3.2 搜索框交互

| 操作 | 反馈 |
|------|------|
| 输入文字 | 右侧显示清除按钮 |
| 点击清除 | 清空输入，自动刷新列表 |
| 按下 Enter | 触发搜索 |
| 失去焦点 | 不自动搜索（避免误触发） |

## 4. 筛选器设计

### 4.1 标准 Select 筛选器

```
┌─────────────┐
│ 朝代        │  ← placeholder 态：灰色文字
└─────────────┘
┌─────────────┐
│ 唐      ✓   │  ← 选中态：显示选中值
└─────────────┘
```

**规格**：
| 属性 | 值 |
|------|-----|
| 宽度 | 根据内容自适应，最小 80px |
| 高度 | 36px（与搜索框一致） |
| 圆角 | 8px |
| 激活态 | `border-primary text-primary` |

### 4.2 行内按钮组（搜索范围）

```
┌──────┬──────┬──────┐
│ 全部 │ 标题 │ 作者 │
└──────┴──────┴──────┘
  ↑ 未选中：透明底，灰字
  ↑ 选中：主色底，白字
```

**规格**：
| 属性 | 值 |
|------|-----|
| 高度 | 32px |
| 内边距 | 6px 12px |
| 字号 | 12px |
| 选中色 | `bg-primary text-primary-foreground` |
| 未选中色 | `text-muted-foreground` |
| 圆角 | 6px，整组外侧圆角 |

## 6. 筛选状态展示

### 6.1 筛选标签（Filter Tags）

当任何筛选条件激活时，在筛选栏下方显示：

```
┌────────────────────────────────────────────────────────────────────────────────┐
│  已筛选：[唐朝 ✕] [已发布 ✕] [月亮 ✕] [翻译:有 ✕] [清除全部]                  │
└────────────────────────────────────────────────────────────────────────────────┘
```

**规格**：
| 属性 | 值 |
|------|-----|
| 样式 | `Badge variant="secondary"` |
| 高度 | 24px |
| 内边距 | 2px 8px |
| 清除图标 | X，12px，点击清除该筛选 |
| 字号 | 12px |

## 7. 推荐实现

### 7.1 最终布局

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                                                                                │
│  🔍 搜索标题、作者或内容...                                                    │
│                                                                                │
│  [全部|标题|作者]  [朝代▼] [状态▼] [标签▼] [更多筛选▼]                       │
│                                                                                │
│  已筛选：[唐朝 ✕] [月亮 ✕]                              [清除全部]             │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 组件结构

```vue
<!-- 筛选栏 -->
<FilterBar>
  <!-- 第一行：搜索框 -->
  <SearchInput
    v-model="keyword"
    placeholder="搜索标题、作者或内容..."
    @search="handleSearch"
    @clear="handleClear" />

  <!-- 第二行：筛选器 -->
  <FilterRow>
    <SearchScopeButtons v-model="searchScope" />
    <SelectFilter v-model="dynasty" :options="dynastyOptions" placeholder="朝代" />
    <SelectFilter v-model="status" :options="statusOptions" placeholder="状态" />
    <TagFilterButton v-model="tagFilter" :tags="availableTags" />
    <AdvancedFilterButton>
      <AdvancedFilters>
        <RadioFilter v-model="hasTranslation" label="翻译" />
        <RadioFilter v-model="hasAppreciation" label="赏析" />
      </AdvancedFilters>
    </AdvancedFilterButton>
  </FilterRow>

  <!-- 第三行：筛选标签（有筛选时显示） -->
  <FilterTags v-if="hasActiveFilters">
    <FilterTag v-for="filter in activeFilters" :key="filter.key">
      {{ filter.label }}
      <X @click="clearFilter(filter.key)" />
    </FilterTag>
    <ClearAllFiltersButton>清除全部</ClearAllFiltersButton>
  </FilterTags>
</FilterBar>
```

## 8. 动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 筛选面板展开 | Fade in + Slide down | 200ms |
| 筛选标签出现 | Fade in + Scale from 0.95 | 150ms |
| 清除筛选 | Fade out + 列表刷新 | 150ms |
| Select 展开 | Fade in | 100ms |

---

## 9. 响应式

### 9.1 桌面（≥ 1024px）
搜索框 + 筛选器在同一区域，两行布局。

### 9.2 平板（768-1023px）
搜索框全宽，筛选器换行。

### 9.3 手机（< 768px）
搜索框全宽，筛选器折叠到「更多筛选」中。

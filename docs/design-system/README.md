## 设计理念

晓诗管理后台的设计语言以「水墨诗意」为核心，融合中国传统文化元素与现代 UI 设计原则：

| 关键词 | 诠释 |
|--------|------|
| **水墨** | 山水云雾、浓淡相宜，背景如画卷展开 |
| **宣纸** | 暖白基底，温润不刺目，如宣纸承墨 |
| **印章** | 品牌标识，方正有力，点睛识别 |
| **留白** | 疏密有致，呼吸感，不堆砌 |
| **碑帖** | 暗色模式如碑帖拓印，沉稳内敛 |

## 快速参考

### 核心色彩

| 用途 | 亮色模式 | 暗色模式 |
|------|----------|----------|
| 背景 | `#f7f3eb` 暖白 | `#1a1714` 墨黑 |
| 卡片 | `oklch(0.98 0.005 80 / 0.92)` | `oklch(0.15 0.01 60 / 0.85)` |
| 主文字 | `oklch(0.2 0.01 60)` | `oklch(0.92 0.01 80)` |
| 强调色 | `oklch(0.45 0.08 30)` 赭石 | `oklch(0.7 0.06 60)` 金 |

### 字体角色

| 角色 | 字体 | 用途 |
|------|------|------|
| 标题 | Noto Serif SC | 品牌标题、诗句 |
| 正文 | Inter / PingFang SC | 界面文字 |
| 数据 | JetBrains Mono | 数字、代码 |

### 间距基数

基础单位 `4px`，常用间距：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`

## 设计令牌

所有设计令牌定义在 `src/styles/globals.css`：

- `@theme` 块：亮色模式令牌
- `.dark { }` 块：暗色模式覆盖
- `--auth-*` 块：登录页专用令牌

使用方式：`bg-primary`、`text-muted-foreground`、`rounded-lg`

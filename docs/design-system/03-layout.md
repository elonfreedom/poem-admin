## 1. 间距系统

### 1.1 基础单位

```
基础单位 = 4px
```

### 1.2 间距尺度

| Token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 图标与文字间距、紧凑元素 |
| `space-2` | 8px | 相关元素间距、列表项内部 |
| `space-3` | 12px | 表单字段间距 |
| `space-4` | 16px | 卡片内边距、段落间距 |
| `space-6` | 24px | 区块间距、卡片间距 |
| `space-8` | 32px | 大区块间距 |
| `space-12` | 48px | 页面级间距 |
| `space-16` | 64px | 超大间距 |

### 1.3 Tailwind 映射

```css
gap-1  → 4px
gap-2  → 8px
gap-3  → 12px
gap-4  → 16px
gap-6  → 24px
gap-8  → 32px
gap-12 → 48px
gap-16 → 64px
```

## 2. 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `rounded-sm` | 2px | 小标签、角标 |
| `rounded-md` | 4px | 按钮、输入框 |
| `rounded-lg` | 8px | 卡片、弹窗 |
| `rounded-xl` | 12px | 大卡片、模态框 |
| `rounded-2xl` | 16px | 特殊容器 |
| `rounded-full` | 9999px | 头像、按钮（胶囊形） |

### 使用原则

- **小元素小圆角**：按钮、输入框用 `rounded-md` (4-6px)
- **大容器大圆角**：卡片用 `rounded-lg` (8px)
- **品牌元素统一**：印章用 `rounded-md` (6px)

## 3. 阴影

### 3.1 阴影层级

| 层级 | 值 | 用途 |
|------|-----|------|
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` | 微浮动，输入框聚焦 |
| `shadow-md` | `0 4px 6px rgba(0,0,0,0.1)` | 卡片、下拉菜单 |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.1)` | 弹窗、浮层 |
| `shadow-xl` | `0 20px 25px rgba(0,0,0,0.15)` | 模态框、登录卡片 |

### 3.2 登录页专用

```css
--auth-shadow-card: 0 24px 80px oklch(0 0 0 / 0.12);  /* 亮色 */
--auth-shadow-card: 0 24px 80px oklch(0 0 0 / 0.5);   /* 暗色 */
```

## 6. 毛玻璃效果（Glassmorphism）

```css
/* 卡片毛玻璃 */
.glass-card {
  background: var(--auth-bg-card);
  backdrop-filter: blur(24px) saturate(1.2);
  -webkit-backdrop-filter: blur(24px) saturate(1.2);
  border: 1px solid var(--auth-border);
}

/* 顶栏毛玻璃 */
.glass-header {
  background: oklch(1 0 0 / 0.8);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
}
```

### 使用场景

- 登录卡片
- 顶栏（滚动时）
- 浮层、弹窗

## 7. 使用规则

### 7.1 间距原则

1. **相关元素靠近**：标签与输入框间距 < 输入框之间间距
2. **区块间留白**：不同功能区块间距 ≥ 24px
3. **页面边距**：内容区与视口边缘 ≥ 16px（移动端）/ ≥ 24px（桌面）

### 7.2 对齐原则

1. **左对齐为主**：表单、列表左对齐
2. **居中为例外**：标题、按钮组可居中
3. **数字右对齐**：表格数字列右对齐

### 7.3 层级原则

1. **z-index 管理**：顶栏 40 > 侧边栏 50 > 弹窗 100
2. **阴影表达层级**：阴影越大，层级越高
3. **毛玻璃隔离**：浮动元素使用毛玻璃与背景隔离

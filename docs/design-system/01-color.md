# 色彩系统

> 基于 oklch 色彩空间，感知均匀，适合亮色/暗色双模式

---

## 1. 色彩空间

所有颜色使用 **oklch** 色彩空间：
- `l` = 亮度 (0-1)
- `c` = 色度 (0-0.4)
- `h` = 色相 (0-360)

优势：亮度变化时色相不变，暗色模式转换更自然。

## 7. 使用规则

### 7.1 颜色应用原则

1. **背景层次**：页面背景 < 卡片背景 < 输入框背景，依次递增不透明度
2. **文字对比**：主要文字与背景对比度 ≥ 4.5:1（WCAG AA）
3. **语义一致**：同一状态使用同一令牌，不随意创建新颜色
4. **暗色适配**：所有颜色必须定义亮色和暗色两套值

### 7.2 令牌引用

```css
/* 正确：使用令牌 */
.card {
  background: var(--auth-bg-card);
  color: var(--auth-fg-primary);
  border: 1px solid var(--auth-border);
}

/* 错误：硬编码颜色 */
.card {
  background: rgba(255, 255, 255, 0.9);
  color: #333;
}
```

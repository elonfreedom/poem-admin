# 分类与标签管理 — UI/UX 设计文档

> **版本**：v1.0 · **日期**：2026-09-06
> **设计系统**：水墨诗意 · 东方雅韵
> **组件库**：shadcn-vue + Tailwind CSS 4

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **一目了然** | 列表信息密度适中，关键数据（诗歌数）突出显示 |
| **操作可逆** | 删除有二次确认，删除前展示影响范围 |
| **即时反馈** | 所有操作有 toast 反馈，加载有 skeleton |
| **效率优先** | 支持搜索、排序、批量操作 |
| **诗意美学** | 遵循「水墨诗意」设计语言，留白、渐变、印章元素 |

### 2.3 交互状态

| 状态 | 样式 |
|------|------|
| 默认 | 背景透明，文字 foreground |
| 悬停 | `bg-muted/50`，显示操作按钮 |
| 选中（checkbox） | `bg-primary/5` |
| 禁用（有诗歌时禁止选择） | `opacity-50 cursor-not-allowed` |


## 7. 响应式设计

### 7.1 桌面端（≥ 1024px）

- 完整表格展示，所有列可见
- 操作按钮横向排列
- 弹窗宽度 480px

### 7.2 平板端（768px - 1023px）

- 隐藏「创建时间」列
- 操作按钮折叠为 dropdown
- 弹窗宽度 100%

### 7.3 移动端（< 768px）

- 表格改为卡片列表
- 每个分类/标签一个卡片
- 弹窗全屏

## 8. 无障碍设计

| 要求 | 实现 |
|------|------|
| 键盘可达 | 所有交互元素 Tab 可达 |
| 焦点可见 | `:focus-visible` 有 ring 样式 |
| ARIA 标签 | 图标按钮有 `aria-label` |
| 颜色非唯一信息 | 错误状态同时有图标和文字 |
| 屏幕朗读 | 表格有 `caption`，操作有描述 |

## 9. 动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 行悬停 | `bg-muted/50` 渐入 | 150ms |
| 弹窗出现 | `opacity + scale` | 200ms |
| 弹窗关闭 | `opacity + scale` | 150ms |
| 删除行 | `opacity → 0` + 高度收缩 | 200ms |
| 新建行 | `opacity 0 → 1` + 高度展开 | 300ms |
| 展开子分类 | 高度展开 | 200ms |
| Toast 出现 | 从右侧滑入 | 200ms |

## 1. 概念定义

### 1.1 分类（Category）

分类是诗歌的**归属体系**，用于定义诗歌的门类和层级关系。

| 属性 | 说明 |
|------|------|
| **层级** | 树状结构，支持父子层级（如「唐诗 > 五言 > 绝句」） |
| **数量约束** | 一首诗**只能属于一个**分类 |
| **用途** | 定义诗歌的归属门类，如「诗经」「唐诗」「宋词」「元曲」 |
| **特性** | 预设体系，变更频率低，有排序值 |
| **删除策略** | 有关联诗歌时**禁止删除**（防止数据孤儿） |

### 1.2 标签（Tag）

标签是诗歌的**特征标记**，用于多维度描述诗歌的属性。

| 属性 | 说明 |
|------|------|
| **层级** | 扁平结构，无层级 |
| **数量约束** | 一首诗**可以有多个**标签 |
| **用途** | 描述诗歌的主题、情感、意象等，如「思乡」「山水」「爱情」「月亮」 |
| **特性** | 灵活自由，可随时新增，无排序 |
| **删除策略** | 删除不影响诗歌本身（仅解除关联） |

### 1.3 对比总结

| 维度 | 分类 | 标签 |
|------|------|------|
| 关系类型 | 一对多（一个分类 → 多首诗） | 多对多（标签 ↔ 诗歌） |
| 数量限制 | 每首诗 1 个 | 每首诗 0-N 个 |
| 结构 | 树状层级 | 扁平 |
| 变更频率 | 低 | 高 |
| 必填性 | 可选 | 可选 |
| 典型示例 | 「唐诗三百首」「宋词」 | 「李白」「月亮」「豪放」「中秋」 |

## 2. 功能需求

### 2.1 分类管理

#### 2.1.1 分类列表

| 项目 | 说明 |
|------|------|
| **入口** | 侧边栏「内容管理 > 分类管理」 |
| **路由** | `/category` |
| **展示** | 表格（ID、名称、父级、排序值、诗歌数、操作） |
| **排序** | 默认按 sort 值升序，再按 ID 升序 |
| **层级展示** | 子分类缩进展示，视觉区分层级 |

#### 2.1.2 创建分类

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | input | ✅ | 分类名称（max 50 字符，同级唯一） |
| parent_id | select | ❌ | 父级分类（不选则为顶级） |
| sort | number | ❌ | 排序值（默认 0，越大越靠前） |

**校验规则**：
- 名称不能为空
- 同级下名称唯一
- 父级不能选择自身（编辑时）
- 父级不能选择自己的子级（防止循环）

#### 2.1.3 编辑分类

| 项目 | 说明 |
|------|------|
| **可修改字段** | 名称、父级、排序值 |
| **校验规则** | 同创建 |
| **关联影响** | 修改父级后，子分类跟随移动 |

#### 2.1.4 删除分类

| 项目 | 说明 |
|------|------|
| **确认** | 二次确认弹窗 |
| **约束** | 有**关联诗歌**时禁止删除，提示「该分类下还有 N 首诗歌，请先转移」 |
| **级联** | 有**子分类**时禁止删除，提示「该分类下还有子分类，请先删除子分类」 |
| **成功后** | 刷新列表，toast 提示「删除成功」 |

---

### 2.2 标签管理

#### 2.2.1 标签列表

| 项目 | 说明 |
|------|------|
| **入口** | 侧边栏「内容管理 > 标签管理」 |
| **路由** | `/tag` |
| **展示** | 表格（ID、名称、诗歌数、创建时间、操作） |
| **排序** | 默认按 ID 降序（最新创建在前） |
| **搜索** | 支持按名称模糊搜索 |

#### 2.2.2 创建标签

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | input | ✅ | 标签名称（max 30 字符，全局唯一） |

**校验规则**：
- 名称不能为空
- 名称全局唯一（不区分大小写）
- 去除首尾空格后校验

#### 2.2.3 编辑标签

| 项目 | 说明 |
|------|------|
| **可修改字段** | 名称 |
| **校验规则** | 同创建 |

#### 2.2.4 删除标签

| 项目 | 说明 |
|------|------|
| **确认** | 二次确认弹窗，提示「确定删除标签「xxx」？删除后将从相关诗歌移除」 |
| **约束** | 无硬约束，允许删除 |
| **关联影响** | 删除后自动解除与所有诗歌的关联，诗歌本身不受影响 |
| **成功后** | 刷新列表，toast 提示「删除成功」 |

---

### 2.3 诗歌中的分类与标签

#### 2.3.1 创建/编辑诗歌时的选择

| 字段 | 组件类型 | 说明 |
|------|----------|------|
| category | Select（单选） | 分类下拉，展示层级路径（如「唐诗 > 五言」） |
| tags | Multi-Select | 标签多选，支持搜索已有标签 |

#### 2.3.2 诗歌列表中的展示

| 列 | 展示方式 |
|------|----------|
| 分类 | 显示分类名称，无分类显示「-」 |
| 标签 | Badge 列表，最多显示 3 个，超出显示「+N」 |

#### 2.3.3 诗歌列表筛选

| 筛选器 | 类型 | 说明 |
|------|------|------|
| 分类 | Select（单选） | 选择分类，筛选该分类下所有诗歌 |
| 标签 | Multi-Select | 选择标签，筛选包含任一标签的诗歌（OR 逻辑） |

## 3. API 接口

### 3.1 分类接口

| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| GET | `/api/admin/categories` | 分类列表（树状） | - | `Category[]` |
| POST | `/api/admin/categories` | 创建分类 | `{ name, parent_id?, sort? }` | `Category` |
| PUT | `/api/admin/categories/:id` | 更新分类 | `{ name?, parent_id?, sort? }` | `Category` |
| DELETE | `/api/admin/categories/:id` | 删除分类 | - | - |

**Category 数据结构**：
```typescript
interface Category {
  id: number;
  name: string;
  parent_id: number | null;
  sort: number;
  poem_count: number;
  children?: Category[];      // 子分类（列表时返回）
  created_at: string;
}
```

### 3.2 标签接口

| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| GET | `/api/admin/tags` | 标签列表 | - | `Tag[]` |
| POST | `/api/admin/tags` | 创建标签 | `{ name }` | `Tag` |
| PUT | `/api/admin/tags/:id` | 更新标签 | `{ name }` | `Tag` |
| DELETE | `/api/admin/tags/:id` | 删除标签 | - | - |

**Tag 数据结构**：
```typescript
interface Tag {
  id: number;
  name: string;
  poem_count: number;
  created_at: string;
}
```

### 3.3 诗歌关联接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/poems?category_id=1` | 按分类筛选诗歌 |
| GET | `/api/admin/poems?tag_ids=1,2,3` | 按标签筛选诗歌 |
| PUT | `/api/admin/poems/:id` | 更新诗歌（含 category_id, tag_ids） |

## 5. 数据库设计参考

### 5.1 categories 表

```sql
CREATE TABLE categories (
  id         INT PRIMARY KEY AUTO_INCREMENT,
  name       VARCHAR(50) NOT NULL,
  parent_id  INT DEFAULT NULL,
  sort       INT DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (parent_id) REFERENCES categories(id) ON DELETE RESTRICT,
  UNIQUE KEY uk_name_parent (name, parent_id)
);
```

### 5.2 tags 表

```sql
CREATE TABLE tags (
  id         INT PRIMARY KEY AUTO_INCREMENT,
  name       VARCHAR(30) NOT NULL UNIQUE,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5.3 poem_tag 关联表

```sql
CREATE TABLE poem_tag (
  poem_id    INT NOT NULL,
  tag_id     INT NOT NULL,
  PRIMARY KEY (poem_id, tag_id),
  FOREIGN KEY (poem_id) REFERENCES poems(id) ON DELETE CASCADE,
  FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);
```

### 5.4 poems 表变更

```sql
ALTER TABLE poems ADD COLUMN category_id INT DEFAULT NULL;
ALTER TABLE poems ADD FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL;
```

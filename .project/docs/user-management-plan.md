# 用户管理功能实施计划

## 一、需求概述

在后台管理系统中新增「用户管理」模块，用于管理**前端 App 用户**（非后台管理员）。

### 业务背景
- 前端用户：通过 App 注册/登录的用户，可以浏览诗歌、打卡等
- 后台管理用户：通过后台登录的管理员，负责管理内容
- 两类用户完全分离，用户管理模块仅管理前端用户

## 二、功能清单

| 功能 | 优先级 | 说明 |
|-----|--------|------|
| 用户列表 | P0 | 分页展示前端用户，支持筛选（昵称、手机号、状态） |
| 用户详情 | P0 | 查看用户详细信息（注册时间、活跃度等） |
| 禁用/启用用户 | P0 | 封禁违规用户，恢复已禁用用户 |
| 重置密码 | P1 | 管理员可重置用户密码 |

## 三、页面设计

### 用户列表页
- **路径**: `/user/list`
- **菜单标题**: 用户管理
- **功能**:
  - 分页展示用户列表
  - 筛选条件：关键词（昵称/手机号）、状态（正常/禁用）、注册时间范围
  - 列表字段：ID、昵称、手机号、头像、状态、注册时间、最后登录时间
  - 操作按钮：查看详情、禁用/启用

### 用户详情弹窗
- 展示用户完整信息
- 显示用户统计数据（打卡天数、收藏数等）
- 可执行禁用/启用操作

## 四、API 接口需求

| 方法 | 路径 | 说明 |
|-----|------|------|
| GET | /api/admin/users | 用户列表（分页、筛选） |
| GET | /api/admin/users/:id | 用户详情 |
| PUT | /api/admin/users/:id/status | 更新用户状态（禁用/启用） |
| PUT | /api/admin/users/:id/reset-password | 重置用户密码 |

### 请求参数

**用户列表**
```
GET /api/admin/users?page=1&page_size=20&keyword=&status=&start_date=&end_date=
```

**用户状态更新**
```
PUT /api/admin/users/:id/status
Body: { "status": "active" | "disabled" }
```
